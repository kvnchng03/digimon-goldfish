# Generated app icons

These PNG files are generated from `../icon.svg` with `npm run generate-icons` in `guide/`.
Edit the SVG source and rerun the command instead of editing PNGs.
The renderer uses Playwright with installed Google Chrome locally or Playwright Chromium when `CI` is set.
The opaque navy background and centered Digimon Card Game logo keep the artwork inside the maskable icon's safe area.
The logo is embedded in the SVG so the favicon, generated icons and portable export work without external image requests.
Logo source: [official Digimon Card Game website](https://world.digimoncard.com/images/common/header/img_logo.png?v=2), retrieved October 7, 2026.
