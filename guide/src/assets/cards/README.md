# Card artwork

Official English sample images downloaded on 7 Oct 2026 from Bandai's Digimon Card Game card list.
The source URL for each file is `https://world.digimoncard.com/images/cardlist/card/{card-number}.png`.
Card details are available at `https://world.digimoncard.com/cards/?card_no={card-number}&search=true`.
Original artwork and SAMPLE marks are retained without alteration.
Digimon and card artwork belong to their respective rights holders.

The card catalog in `src/cards.ts` maps each filename to a card name and teaching role.
The guide links each enlarged card to its official details and credits artwork in its source notes.
